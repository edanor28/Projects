# Asistente Financiero - Scaffold

Scaffold inicial para la app móvil (Expo + TypeScript). Contiene modelos WatermelonDB, utilidades de validación y un stub para el cliente de IA en la nube.

Seguridad y recomendaciones iniciales:
- Nunca poner claves en el repositorio. Usar variables de entorno y servicios de secreto.
- Revisar dependencias antes de instalar (auditar, firmlock).
- Ejecutar `npm run typecheck` y `npm run lint` antes de commits.

Pasos rápidos:

```powershell
npm install
npm run start
```
